### 翻车与返工

- **紧凑窗口下账算不平（builder check 预警成真）**：system 1114 +
  tools 1386 + 输出余量 1024 = 3524 > total 2048，差额为负。保底
  400 token 让它从「每轮全截光」变成受控行为——紧凑窗口就是靠这个
  兜底撑起 25 轮验收的
- **args_schema 出不了 JSON schema**：ToolRuntime 注入的 callable
  字段让 model_json_schema() 炸掉，改用 tool_call_schema（排除注入
  字段）实测工具定义 token
- **测试水位线用 10**9 想模拟「覆盖全部」，结果把测试自己后 append
  的消息（真实自增 id 远小于 10**9）也过滤掉了——水位线语义是
  「读快照的 max(id)」，测试数据要按真实语义构造
