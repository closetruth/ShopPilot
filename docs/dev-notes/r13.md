### 我的纠偏

1. **注入方式的理解**：我最初提了三种方案（判定后注入 / 每轮注入 / 工具内注入），
   用户指出「不是检索后才注入 prompt 吗」「在工具里面注入」。确认是 A 方案——
   不改 LangGraph 图结构，注入发生在工具返回值内部。

2. **首尾排布的实现**：用户原意是 top10 严格首尾交错。我判断机械交错
   （1,2,7,6,5,4,3,10,9,8）会造成阅读混乱，改为分两段（高相关 / 补充）。
   **这是偏离原意的取舍**，已在设计文档中标注，若评估显示需要严格交错再改。

3. **精排阈值 0.58**：用户直接指定。我提示了量纲差异（余弦相似度 vs 交叉编码器
   打分），并按用户要求写进设计，但标注「待评估验证」。
