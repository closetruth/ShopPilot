### 翻车与返工

- **PyMySQLSaver 不支持 async**：图运行时调 aget_tuple/aput 直接抛
  NotImplementedError。换 AIOMySQLSaver（aiomysql 驱动）；连接必须建在
  事件循环内，get_checkpointer 变 async、lifespan 预热
- **aiomysql × pymysql 1.2+ 不兼容**：pymysql 把 escape_bytes_prefixed
  换成哨兵字符串「DO NOT IMPORT THIS!!!」（issue #1274），aiomysql 恰好
  import 了它，blob 写入即崩。monkeypatch 指回 escape_bytes 真实现
- **anyio 每测试新建事件循环**：共享 saver 单例的连接绑死第一个循环，
  第二个测试就 NoneType.send。测试改每用例独立建 saver
- **向量删除后不 flush**：全量回归暴露（与 r15 无关），独立 Milvus 下
  「管理端已删、检索仍命中」，42e23ce 修复
- Task 5 期间 test_retrieval 的 top_k 两个测试随工具接口一起退役
