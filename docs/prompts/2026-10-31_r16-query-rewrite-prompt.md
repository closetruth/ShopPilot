## 本轮任务

Query 标准化。Query 改写，售后、退货退款这类低容错进行改写。

## 背景与依据（开工前已实测）

口语措辞与政策术语之间隔着语义鸿沟，纯向量检索靠相似度硬扛，实测
（47 条 FAQ，BGE-M3）：

| 口语 query | 原分 | 拼术语后 | 现状 |
|---|---|---|---|
| 包装破了 | 0.553 | 0.643 | 被拒答闸挡 |
| 快递好久没动 | 0.619 | 0.771 | 被挡，改写后命中补偿标准 |
| 运费我不要出 | 0.645 | 0.729 | 压线被挡 |
| 东西坏了想退 | 0.675 | 0.727 | 过但分偏低 |

r14 已验证阈值两侧没有可靠分界线（0.63 投诉与 0.657 买一送一之间
无分界），措辞问题要在措辞层解决。

## 已定决策

| 项 | 选择 |
|---|---|
| 改写方式 | 规则词表，零 LLM（改坏风险 + 延迟，先看数据再定 LLM 兜底） |
| 作用范围 | 只进知识检索节点；意图分类仍看顾客原话 |
| 改写形态 | 拼接不替换（保留原话的具体信息与嵌入信号） |
| 回退 | 改写后证据不足时用原话重查，取分高的一组 |
| 留痕 | rewritten_terms / rewritten_query / fallback_used 落 agent_traces detail |
| 词表质量门槛 | 术语必须存在于 FAQ 原文；每条词条必须有实测增益（过闸或 +0.05） |

## 过程裁定（builder check 后）

- 「包装破了」不为单条硬调词条（改写后 0.643 差 0.007 过闸，性价比
  不高）——验收放宽为「显著提升，可能仍拒答」（后续反转：术语对齐
  FAQ 原文后实测 0.683 过闸）
- 「要投诉你们的服务」r14 冻结测试更新为新行为（改写后命中投诉处理
  条款 + 转人工指引，优于生硬拒答）
- 轨迹走 state 加字段（检索节点 → ConversationState → main 落 detail）

## 验收

「包装破了」「快递好久没动」给出带引用的有效回答（改写前被拒答）；
现有检索用例不回退；无关问题仍被拒答；trace 里能查到改写词条；
全量测试通过。
