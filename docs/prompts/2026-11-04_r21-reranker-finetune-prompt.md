## 本轮任务

把飞轮攒下来的低置信度问题，做成一次可复算的精排模型微调。

低置信度表现在有 265 条，全部是 `low_score`——检索**找到了**东西，但最高分
不够 0.65，被闸拦下。这批数据天然是「措辞与条款之间存在鸿沟」的样本，正对
精排的靶心。

用哈工大讯飞 `chinese-roberta-wwm-ext` 做全参微调，任务是 cross-encoder
相关性打分，训练完导出 ONNX 做推理服务化。

数据处理链路：
- 数据清洗：去重、长度、噪声、PII 掩码、跨源合并
- 分层抽样：按 category × label，70/15/15
- 数据增强：轨迹改写配对、规则同义词、hard negative
- 标注：管理页逐条确认，LLM 只给建议
- 训练：远端 docker 容器，全参微调
- 评估：三把尺（离线指标 / 低置信度回放 / r20 端到端回归）
- 部署：`RERANK_ENABLED` 开关切换，随时回滚
- 前端配套：标注页、数据集页、训练发布页

## 验收标准

- 265 条可在标注页 20 分钟内标完，三类分布可见
- 清洗漏斗与分层分布可查，数据集可导出
- 远端容器能跑完一次训练并导出 ONNX，指标落库
- 三把尺不达标时激活被拒绝
- `RERANK_ENABLED=1` 后，原本拒答的低置信度问题能答对且引用正确
- `RERANK_ENABLED=0` 一键回到 r20 行为，对话无回归

## 需要知道的坑

- 本机无 NVIDIA GPU，HuggingFace 不可达：训练只能在远端容器，镜像站
  `HF_ENDPOINT=https://hf-mirror.com` 必须配
- 线上知识路径**本来就没走精排**（`hybrid_rerank` 只在评估脚本里跑过），
  接进来是行为变更，必须带开关与端到端回归
- 精排输出是 sigmoid 分，与 BGE-M3 余弦不可比，旧阈值 0.58/0.65 不能复用
- 265 条里可能大半是知识库缺失，诊断闸先判，可回答不足 80 条就停
- 训练依赖不进 `pyproject.toml`，本地 uv 环境保持轻量
- 远端 `3307` 与 `3005` 端口未开放，新端口要先确认，必要时走 SSH 隧道
