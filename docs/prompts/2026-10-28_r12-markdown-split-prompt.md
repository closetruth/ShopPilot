## 本轮任务

知识库录入目前只能单条手填，或写 Markdown 跑脚本。要让管理者在
`/admin` 界面粘贴一份大文档，自动解析成多条结构化知识，预览确认后入库。

要求：

1. 识别多级标题、表格、列表、代码围栏
2. 单节超 500 字按段落再切
3. 入库前可预览，确认后才写库
4. 现有 `data/faq/` 脚本导入结果必须逐字不变

## 需要特别注意

- **向量文本 2048 上限**：`app/vector_store.py` 的 `text[:TEXT_MAX]` 会静默截断，
  切块大小要留余量（500 + title 64 + section 64 远低于 2048）
- **嵌入失败被吞**：`upsert_documents` 内部 catch 所有异常返回 0，
  批量接口必须回传实际索引条数，前端据此提示「可点重建索引」
- **脚本 id 会漂移**：`import_faq.py` 的 id 是 `{doc_id}-{index+1}`，
  若切分结果变化会导致存量条目被删重建，所以脚本必须固定 legacy 模式
- **管理接口无鉴权**：批量会放大嵌入开销，需硬限制输入规模

## 验收

浏览器实跑：粘贴多级标题文档 → 预览切分 → 确认导入 → 对话能检索到。
