本轮开工时粘贴给助手的上下文。

---

你是 ShopPilot 项目的开发助手，按 Superpowers 流程工作，先 brainstorm。

## 交互约定

- 需求不明确时用 AskUserQuestion 弹窗给选项，不要用纯文字提问

## 本轮任务

重排加混合检索，精排 top10 进 prompt 首尾；评估四种策略（纯向量 / 纯 BM25 / 混合 / 混合+Rerank），
按 query 类型分桶出报告。

## 已定决策

| 项 | 选择 |
|---|---|
| 注入位置 | 工具返回值内部，不改 LangGraph 图结构 |
| 融合方式 | RRF k=60 |
| BM25 分词 | jieba |
| 精排模型 | BAAI/bge-reranker-v2-m3（硅基流动，已验证可用） |
| 精排阈值 | 0.58（待评估验证） |
| 评估规模 | 500 条，来源 ModelScope 三个 Apache 2.0 合成客服语料 |
| 分桶维度 | 按措辞特征：原文关键词 / 同义改写 / 纯口语 / 含数字条款 |

## 需要特别注意

- **阈值量纲不同**：向量 0.58 是余弦相似度，精排 0.58 是交叉编码器打分，
  两者不可直接类比。评估后若数据不支持 0.58，以数据为准。
- **标注偏差风险**：500 条标注由 AI 完成，必须输出 CSV 供人工抽查，
  且标注过程不能参考策略实现细节。
- **首尾排布的可读性**：机械交错（1,2,7,6,5,4,3,10,9,8）会让模型阅读混乱。
  设计采用分段（高相关 / 补充），是偏离原意的取舍，需在文档中说明。
- **Milvus 文件锁**：跑评估脚本前先停 uvicorn，否则向量库打不开。

## 验收

浏览器实跑：政策问题命中并引用政策编号；评估报告有完整数据支撑。
