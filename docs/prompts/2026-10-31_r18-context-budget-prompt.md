## 本轮任务

会话上下文：system 提示词，工具，梗概，原文。

摘要提示词只提炼事实与诉求（问过哪款商品、报过的订单号手机号、
明确诉求、还没解决的问题），对话里没出现的内容一个字不许编，
寒暄闲聊不留。摘要走后台异步。

历史分成两段，一段是原文，一段是梗概。梗概单开一张表，不写到
原始消息里。原文超了就进行梗概压缩。

token 预算从模型窗口倒推，减去系统提示词那些。token 计算要准确，
中文和 token 对应。上下文可观测。
