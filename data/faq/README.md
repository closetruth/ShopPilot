## 许可状态（重要）

**该仓库未包含 LICENSE 文件。**

按著作权法默认规则，无明示许可即表示保留所有权利。将这些文件复制进本项目
并随仓库分发，严格来说超出了默认允许范围。

因此：

- 这些文档目前仅用于**本地开发与演示**
- 对外发布或商用前，必须二选一：
  1. 联系仓库作者取得明确授权
  2. 替换为本店自行编写的真实政策（推荐，本来也应该用自家条款）

## 内容性质

文档中的条款（如「运费险单笔最高 12 元」「仓库签收后 48 小时质检」）是
**演示用的虚构规则**，不代表任何真实平台的政策。顾客若据此产生预期，
会与实际服务不符。

上线前必须替换为真实政策文本。

## 替换方式

1. 把新政策按同样格式放入 `data/faq/`：

   ```markdown
   ---
   id: P-RET-001
   title: 七天无理由退货规则
   category: 退货
   version: 2026-11-01
   ---

   ## 适用条件

   正文…

   ## 运费承担

   正文…
   ```

2. 执行导入：

   ```bash
   uv run python -m scripts.import_faq
   ```

3. 重建向量索引：

   ```bash
   uv run python -m scripts.reindex --drop
   ```

小节按 `## ` 二级标题切分，每条独立检索。小节名建议写具体（「运费承担」
优于「其他说明」），因为它会参与向量化。
