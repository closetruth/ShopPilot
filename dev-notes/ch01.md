### 我（用户）这一步发的关键原话

> 我要用 Superpowers 模式做一个电商智能客服系统,第一步先跑通纯对话。
>
> 功能：多轮 + SSE 流式；PromptTemplate；with_structured_output 抽售后字段；历史裁剪 + token 预算。
> 技术栈：Python + FastAPI + LangChain；OpenAI 协议接上游；.env 配地址/模型/密钥。
> 本章不做工具调用 / Agent。

> 工作要求：全程 Superpowers；不可单测处用标注样例；聊天页 Vibe Coding；dev-notes 追记；库文档先 Context7；选型矛盾停问；完结交演示命令/测试/dev-notes。

后续纠偏与选择（对话中）：
- 历史：先选「客户端 messages + session_id 预留不落库（C）」，后纠偏为 **要会话存储** → **SQLite + SQLAlchemy（B）** → 交互 **只传 session_id + 本轮 message（A）**
- 抽取：两者都做（独立 `/extract` + `mode=extract`）
- 聊天页：本章做（B，Vibe Coding）
- 裁剪：token 预算 + 轮数硬上限可配置（C）
- 诉求枚举：B（8 类含 cancel/logistics/invoice）
- 架构方案：方案 1（薄 FastAPI + LangChain LCEL）
